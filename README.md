# BSC Crypto Wallet

A simple cryptocurrency wallet application built on the **Binance Smart Chain (BSC)** network.

## About the Project

BSC Crypto Wallet allows users to create a new wallet on the real BSC blockchain. It displays the generated wallet address, while the private key is securely stored locally on the user's device.

The application also automatically detects and displays tokens received at the wallet address.

## Features

- **Wallet Creation** – Create a new wallet on the BSC network.
- **Wallet Address** – View the generated public wallet address.
- **Private Key Storage** – Store the private key locally on the device.
- **Token Detection** – Automatically detect tokens received in the wallet.
- **Token Display** – View received on-chain tokens.

## Blockchain Network

- Binance Smart Chain (BSC)
- Real Blockchain Integration

## Project Scope

This project focuses on basic crypto wallet functionality, including wallet creation, local private key storage, and displaying received tokens. Sending tokens and trading features are not included.
