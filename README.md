# BSC Crypto Wallet

A simple cryptocurrency wallet application built on the **Binance Smart Chain (BSC)** network.

---

## About

BSC Crypto Wallet is a cryptocurrency wallet application that allows users to create a new wallet on the real Binance Smart Chain blockchain. It displays the generated public wallet address, while the private key is stored locally on the user's device.

The application automatically detects and displays tokens received at the wallet address, providing a simple way to view on-chain token information.

## Features

| Feature                 | Description                                         |
| ----------------------- | --------------------------------------------------- |
| **Wallet Creation**     | Create a new wallet on the BSC network.             |
| **Wallet Address**      | View the generated public wallet address.           |
| **Private Key Storage** | Store the private key locally on the device.        |
| **Token Detection**     | Automatically detect tokens received in the wallet. |
| **Token Display**       | View received on-chain tokens.                      |

## Blockchain Network

- **Network:** Binance Smart Chain (BSC)
- **Integration:** Real Blockchain Network
- **Token Information:** Retrieved from on-chain data

## Project Scope

The project focuses on basic cryptocurrency wallet functionality, including wallet creation, local private key storage, wallet address display, and viewing received on-chain tokens.

Token sending and trading functionalities are not included.
